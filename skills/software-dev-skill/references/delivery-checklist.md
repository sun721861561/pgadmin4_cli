# Delivery Checklist

## Before Editing

- Confirm the requested behavior and constraints.
- Identify files most likely to contain the change.
- Note any compatibility or migration concerns.

## During Editing

- Keep the patch minimal and focused on the request.
- Preserve existing patterns unless change is explicitly required.
- Update or add tests when behavior changes.

## Before Final Response

- Run targeted verification commands.
- Record command outcomes and unresolved blockers.
- List changed files and why each changed.
- Call out residual risks and concrete next checks.
